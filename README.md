# My Body Log v0.2

個人用の体組成記録アプリです。HTML、CSS、Vanilla JavaScriptのみで動作し、入力データはブラウザーのIndexedDBに保存します。外部APIやログイン機能はありません。

## 起動と公開

`index.html`をHTTPサーバーで配信してください。GitHub Pagesではリポジトリの **Settings → Pages** で公開元ブランチとフォルダーを選択します。公開されたHTTPS URLをiPhone Safariで開き、共有メニューから「ホーム画面に追加」を選べます。PWAとService WorkerにはHTTPS（またはlocalhost）が必要です。

## HealthPlanet画像入力

「HealthPlanet画像から入力」で画像を選びます。OCRは同梱のTesseract.js 7を使い、端末のブラウザー内で処理します。画像の通信・IndexedDB保存は行いません。最初の読み取り後、抽出値を入力欄と確認一覧で確認・修正してから保存してください。画像は処理完了時に破棄されます。

OCR位置決めは画面全体に対する固定座標ではなく、縮小画像から体組成表の5本の横罫線と左右の外枠を検出し、その表上端を基準にします。表の各行・列と表直上の体重表示から項目別のROIを作り、数字OCRします。対象項目は体重、体脂肪率、筋肉量、BMI、内臓脂肪レベル、基礎代謝量、体内年齢、推定骨量、筋質点数、体水分率、脈拍です。認識失敗は空欄にし、範囲外や信頼度が低い値には警告を出します。読み取り値は既存入力フォームへ反映されるので、内容を確認してから保存してください。日付と時刻は読み取らないため、保存前にフォームを確認してください。開発用のデバッグ画像はURL末尾に`?ocrdebug=1`を付けたときだけ有効になり、各OCR切り出し部分を画面表示できます。スクリーンショットや切り出し画像は端末内のメモリーだけで扱い、ファイルやIndexedDBへ保存しません。

OCRは誤認識することがあります。範囲外の数値は入力欄へ反映せず、低信頼度や前回との差が大きい値は確認表示します。画面レイアウト変更などで表の枠を検出できない場合はOCRを中断し、手入力できます。大きな画像は25MBまたは3600万画素を超えると読み込みません。

## オフライン

Service Worker v7はアプリ本体、OCR画面、ライブラリを先行キャッシュします。OCR Worker、WASM、英語学習データは初回OCR時に遅延取得され、同一オリジンキャッシュへ追加されます。初回OCR前の完全オフライン状態ではOCRを開始できません。既存記録の閲覧・編集はオフラインで利用できます。

## データ

- 記録は利用中のブラウザーとサイトのIndexedDBに保存されます。端末やブラウザーを変えると自動では引き継がれません。
- ブラウザーのサイトデータを消す前に、設定画面からJSONバックアップを作成してください。
- JSON復元は現在の記録を置き換えます。復元前に確認画面が表示されます。
- AI相談機能は文章を端末内で生成し、外部へ自動送信しません。
- 健康管理の記録用であり、医療診断を行いません。

## OCRライセンス

Tesseract.jsおよびTesseract.js-coreのライセンスは`vendor/tesseract/`内に同梱しています。
